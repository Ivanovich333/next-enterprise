# 📝 Руководство по редактированию контента

## Что где редактируется

### 🗄️ Через Админ-панель (База данных)

#### 1. **Портфолио (Проекты)**
- **Где**: http://localhost:3002/admin/portfolio
- **Что можно**: Добавлять, редактировать, удалять проекты
- **Поля**:
  - Название
  - Описание
  - URL изображения
  - Категория (Квартира/Дом/Офис)
  - Локация
  - Площадь
  - Год
  - Опубликовано (вкл/выкл)
  - Порядок сортировки

**Отображается на**:
- Главная страница (секция "Наши проекты")
- Страница портфолио (`/portfolio`)

#### 2. **Отзывы**
- **Где**: http://localhost:3002/admin/reviews *(временно через Prisma Studio)*
- **Что можно**: Добавлять, редактировать, удалять отзывы
- **Поля**:
  - Имя клиента
  - Проект
  - Рейтинг (1-5 звезд)
  - Текст отзыва
  - Аватар (эмодзи)
  - Опубликовано
  - Порядок

**Отображается на**:
- Главная страница (секция "Отзывы клиентов")

**Как редактировать**:
```bash
npm run db:studio
# Откроется http://localhost:5555
# Перейдите в Review → добавьте/измените отзывы
```

#### 3. **Заявки клиентов**
- **Где**: http://localhost:3002/admin/requests
- **Что можно**: Просматривать входящие заявки с сайта
- **Поля** (только чтение):
  - Имя
  - Телефон
  - Email
  - Сообщение
  - Дата/время
  - Статус

**Как заполняется**: Автоматически при отправке формы на сайте

## 🚀 Как применить изменения

### Изменения через админку:
1. Войдите в админку
2. Внесите изменения
3. Нажмите "Сохранить"
4. ✅ Изменения сразу отобразятся на сайте

### Изменения через код:
1. Откройте файл в редакторе
2. Внесите изменения
3. Сохраните файл
4. ✅ Сервер автоматически перезагрузится (Hot Reload)
5. Обновите страницу в браузере

## ⚠️ Важные замечания

1. **Не редактируйте** файлы в папке `node_modules/`
2. **Делайте бэкап** перед значительными изменениями
3. **Тестируйте** изменения локально перед публикацией
4. **Изображения**: Используйте внешние ссылки (Unsplash, Imgur, Cloudinary) или загрузите на хостинг

---

## 🎨 Изменение изображений

### Для проектов портфолио:
1. Загрузите фото на сервис (например, Imgur)
2. Скопируйте прямую ссылку на изображение
3. Вставьте в поле "URL изображения" в админке

### Для партнеров:
1. Найдите логотип в формате SVG или PNG
2. Загрузите на CDN или используйте публичную ссылку
3. Вставьте в код массива `partners`

## 📊 База данных

Вся информация хранится в файле: `prisma/dev.db`

**Просмотр БД**:
```bash
npm run db:studio
```

**Бэкап БД**:
```bash
cp prisma/dev.db prisma/dev.db.backup
```

---

## 🔄 Восстановление тестовых данных

Если нужно вернуть тестовые данные:
```bash
# Удалите БД
rm prisma/dev.db

# Создайте заново
npm run db:migrate

# Заполните тестовыми данными
npm run db:seed
```
