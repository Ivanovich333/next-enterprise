# Инструкция по настройке

## 1. Первоначальная настройка

### Установка зависимостей
```bash
npm install
```

### Создание базы данных
```bash
npm run db:migrate
```

### Создание администратора
```bash
npm run create-admin
# Или с параметрами:
npm run create-admin admin@smarthome.uz password123 "Admin Name"
```

### Заполнение тестовыми данными
```bash
npm run db:seed
```

## 2. Настройка Telegram

1. Откройте Telegram и найдите бота [@userinfobot](https://t.me/userinfobot)
2. Нажмите `/start` чтобы получить ваш Chat ID
3. Добавьте Chat ID в файл `.env`:
```
TELEGRAM_CHAT_ID="ваш_chat_id"
```

## 3. Запуск проекта

### Режим разработки
```bash
npm run dev
```

Сайт будет доступен по адресу: http://localhost:3000

### Админ-панель
Войдите в админку: http://localhost:3000/admin/login

Используйте учетные данные, которые вы создали командой `create-admin`

## 4. Доступные скрипты

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка для продакшена
- `npm run start` - запуск продакшен версии
- `npm run db:studio` - открыть Prisma Studio для просмотра БД
- `npm run db:migrate` - применить миграции БД
- `npm run db:seed` - заполнить БД тестовыми данными
- `npm run create-admin` - создать админа

## 5. Структура админ-панели

### Портфолио (/admin/portfolio)
- Добавление/редактирование проектов
- Загрузка изображений (URL)
- Управление категориями

### Отзывы (/admin/reviews)
- Добавление отзывов клиентов
- Рейтинг и аватары

### Партнеры (/admin/partners)
- Логотипы партнеров
- Ссылки на сайты

### Пакеты (/admin/packages)
- Ценовые пакеты услуг
- Список функций

### Заявки (/admin/requests)
- Просмотр заявок с сайта
- Статусы обработки

## 6. Telegram уведомления

При отправке формы на сайте, в Telegram придет сообщение с:
- Именем клиента
- Телефоном
- Email
- Сообщением
- Временем заявки (по времени Ташкента)

## 7. Адаптация под Узбекистан

В проекте уже настроено:
- ✅ Формат телефона: +998 (XX) XXX-XX-XX
- ✅ Валюта: узбекские сумы
- ✅ Часовой пояс: Asia/Tashkent
- ✅ Локализация на русском языке

## 8. Безопасность

⚠️ Перед развертыванием в продакшен:

1. Измените `NEXTAUTH_SECRET` в `.env`:
```bash
openssl rand -base64 32
```

2. Убедитесь что `.env` добавлен в `.gitignore`

3. Не коммитьте чувствительные данные (токены, пароли)

## 9. Поддержка

При возникновении проблем проверьте:
- Файл `.env` создан и заполнен
- База данных создана (файл `prisma/dev.db`)
- Все зависимости установлены
- Порт 3000 свободен
