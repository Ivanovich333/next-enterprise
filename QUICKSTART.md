## Troubleshooting:

**Проблема**: Форма не отправляется
**Решение**: Проверьте что TELEGRAM_CHAT_ID установлен в .env

**Проблема**: Не могу войти в админку
**Решение**: Убедитесь что создали админа: `npm run create-admin`

**Проблема**: Ошибка БД
**Решение**: Удалите `prisma/dev.db` и запустите `npm run db:migrate && npm run db:seed`

**Проблема**: Не приходят уведомления в Telegram
**Решение**:
1. Проверьте токен бота
2. Убедитесь что Chat ID правильный
3. Запустите бота (отправьте /start)
